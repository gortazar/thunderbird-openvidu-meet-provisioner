OpenVidu Meet Provisioner

Configure your OpenVidu Meet server connection

Server

The base URL of your deployed OpenVidu Meet instance, e.g. https://meet.example.com.

Authentication

The LiveKit / OpenVidu API key used to authenticate REST calls (admin credentials).

The LiveKit / OpenVidu API secret paired with the key above. Stored locally in Thunderbird – never sent anywhere except your configured server.

Identity

The name shown to other participants when you join a room.

Help

To use this extension you need access to a running OpenVidu Meet server. Enter the server URL and optional admin credentials above.

Once saved, the sidebar panel (View → Sidebar → OpenVidu Meet) will list available rooms. Open rooms (with active participants) are shown in bold. Click any room to join it in a new Thunderbird tab.
